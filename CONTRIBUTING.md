# Contributing to VeriCampaign

First off, thank you for considering contributing to VeriCampaign! 

## 🛠️ Development Setup

1. **Fork and Clone**: Fork the repository and clone it to your local machine.
2. **Install Dependencies**: Run `pip install -r requirements.txt` to install the required testing frameworks.
3. **Run Tests**: Ensure all existing contract tests pass by running `pytest test_campaign_escrow.py` before making changes.

## 🚀 Pull Request Process

1. **Security First:** Ensure any new smart contract logic maintains strict Source-Policy guardrails to prevent SSRF vulnerabilities.
2. **AI Consensus:** If changing the AI consensus prompt (`prompt_comparative`), provide test cases showing how the AI responds to edge cases.
3. **Documentation:** Update the `README.md` if your PR introduces new features or alters the UI panels in the frontend command center.
4. **Submit:** Create your Pull Request against the `main` branch.

## 🤝 Code of Conduct

Please be respectful and constructive in issues and pull requests. We are building the future of decentralized AI execution together!
